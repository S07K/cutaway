# Security Policy

Cutaway runs entirely in the browser and has no backend. Even so, bugs in media
parsing, project-file loading (`.cutaway` JSON), or plugin loading can matter.

## Reporting a vulnerability

Please **do not open a public issue.** Report it privately through
[GitHub Security Advisories](https://github.com/S07K/cutaway/security/advisories/new).

Include steps to reproduce and, if possible, a minimal file that triggers the
problem. You'll get an acknowledgement within a few days, and credit in the fix
unless you'd rather stay anonymous.

## Supported versions

Only the latest `main` (deployed at <https://cutaway-one.vercel.app>) receives
security fixes.
